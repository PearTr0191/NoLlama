# NoLlama — dependencies for the OpenVINO NIGHTLY venv (venv-nightly/).

# Built by:  .\install.ps1 -Nightly

# Why a second file instead of bumping requirements.txt: Intel's Qwen3.8-27B
# IRs (OpenVINO/Qwen3.8-27B-int4-ov, published 2026-08-14) need OpenVINO
# 2026.4.0-nightly plus an openvino-genai nightly from 2026-08-14 or later,
# and Intel flags the export EXPERIMENTAL / "not fully validated with
# OpenVINO". Nightly wheels move every day and carry no reproducibility
# promise, so venv/ must keep pointing at requirements.txt — see TODONT.md
# ("Making the nightly OpenVINO stack the default install").
#
# This file deliberately does NOT list openvino / openvino-genai /
# openvino-tokenizers. Those come from the nightly index in a separate pip
# pass so that --pre applies only to them; a blanket --pre over the whole
# file would also pull release candidates of numpy, pillow and friends.
# install.ps1 -Nightly runs both passes. By hand:
#
#   pip install -r requirements-nightly.txt
#   pip install --pre -U openvino openvino-tokenizers openvino-genai \
#       --extra-index-url https://storage.openvinotoolkit.org/simple/wheels/nightly
#
